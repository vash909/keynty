# KEYNTY CMOS CW Keyer
A CW keyer based on the original Minty Keyer project by K4ICY https://www.k4icy.com/weekend_radio_minty_kool_keyer.html

Improvements:
- Removed diodes OR
- Removed BJT keying for OR matrix
- Added CMOS OR Gates
- Changed all the logic gates to Low-Voltage (3.6V max)
- Added sidetone buzzer
- Added power LED
- Added alkaline battery holder (3V AA size x2)
- Reduced overall power consumption
- Added a switch for switching iambic mode (A/B)
- Added a switch for sidetone enable

PCB can be mounted directly on the back of the battery holder.
